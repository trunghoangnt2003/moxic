## Tasks

### 1. Install react-hot-toast

- Add `react-hot-toast` to Moxic.Web
- Create `src/components/shared/Toaster.tsx` — wraps Toaster component with dark theme styling
- Mount in App.tsx above Routes

### 2. Extend Skeleton Components

- In `Skeleton.tsx`:
  - `GameCardSkeleton` — matches GameCard dimensions (thumbnail + text lines)
  - `GameGridSkeleton` — CSS grid of GameCardSkeletons
  - `OrderListSkeleton` — table row skeleton for admin
  - `DetailSkeleton` — hero + content block skeleton for detail pages

### 3. Add Empty States

- **CartDrawer.tsx**: When cart is empty, show `ShoppingBag` icon + "Your cart is empty. Let's fill it with games!" + "Browse Games" button
- **GamesPage.tsx**: When search returns 0 results, show `SearchX` icon + "No games found matching your filters" + "Clear Filters" button
- **OrderList.tsx (admin)**: When no orders, show `Package` icon + "No orders placed yet" / "No orders matching this status" depending on filter state

### 4. Create 404 Page

- Create `NotFoundPage.tsx`:
  - Custom Moxic-branded 404: game-themed illustration + "Oops! This page glitched out" + "Back to Storefront" button
  - Dark theme consistent with rest of app
  - Disappointed ghost/gamepad icon using lucide-react
- Add route in App.tsx: `path="*"` → `NotFoundPage`

### 5. Add Toast Notifications

- CheckoutForm.tsx: `toast.success("Game added to cart!")` with "View Cart" action button on add-to-cart
- API error handling: toast.error() for failed API calls (add-to-cart fail, checkout fail, etc.)
- CartDrawer: toast on remove item

### 6. Add Navigation Gaps

- ConfirmationPage.tsx: Add "Continue Shopping" link below order details

### 7. Form Validation (onBlur)

- CheckoutForm.tsx: wire existing validation to run onBlur in addition to onSubmit
- Show inline error messages when user leaves a field (phone, Xbox email, Xbox password)

### 8. Card Hover & Button Disabled States

- GameCard.tsx: add `hover:-translate-y-1` + shadow transition on hover
- All buttons: add `disabled:opacity-50 disabled:cursor-not-allowed` state
- CheckoutForm submit button: disabled during submission, show spinner

### 9. Admin OrderList Skeleton

- OrderList.tsx: show OrderListSkeleton during initial load
- OrderDetailModal.tsx: show DetailSkeleton while modal content loads
