## Tasks

### 1. Add NuGet Packages

- Add `Resend` to Moxic.Infrastructure.csproj
- Add `Polly.Core` to Moxic.Infrastructure.csproj
- Restore and verify build

### 2. Create Email Interface & Service

- Add `IEmailService` interface to `Moxic.Core/Interfaces/IServices.cs` with methods:
  - `SendNewOrderNotificationToAdminAsync(string orderCode, string customerPhone, decimal totalAmount)`
  - `SendPaymentConfirmedAsync(string toEmail, string orderCode)`
  - `SendGameInstalledAsync(string toEmail, string orderCode, string gameName)`
  - `SendOrderCancelledAsync(string toEmail, string orderCode, string reason)`
  - `SendActionRequiredAsync(string toEmail, string orderCode, string message)`
- Implement `EmailService` in `Moxic.Infrastructure/Services/EmailService.cs`:
  - Inject `IResendClient`, `ILogger<EmailService>`, `IConfiguration`
  - Build ResiliencePipeline with 3 retries (2s, 4s, 8s exponential backoff)
  - Each method calls Resend API with proper HTML body
  - Log warnings on retry, error after 3 failures

### 3. Create Email Templates

Create HTML email templates in `Moxic.Api/Emails/Templates/`:
- `NewOrderAdmin.cshtml` — admin notification with order code, phone, total
- `PaymentConfirmed.cshtml` — customer email: "Payment received, we are installing your game"
- `GameInstalled.cshtml` — customer email: "Game installed! Login instructions"
- `OrderCancelled.cshtml` — customer email: cancellation reason + support contact
- `ActionRequired.cshtml` — customer email: "Update your Xbox info"

Each template is dark-themed HTML with inline CSS, Moxic branding, Vietnamese text.

### 4. Wire Into OrdersController

- In `OrdersController.CreateOrder()`, after `SaveChangesAsync()`:
  - Call `IEmailService.SendNewOrderNotificationToAdminAsync()`
  - Surround with try-catch — notification failure does NOT fail the order

### 5. Wire Into AdminOrdersController

- In `AdminOrdersController.UpdateOrderStatus()`, after successful status change:
  - If new status == Verifying: call `SendPaymentConfirmedAsync()`
  - If new status == Completed: call `SendGameInstalledAsync()`
  - If new status == Cancelled: call `SendOrderCancelledAsync()` with reason
  - All calls in try-catch — email failure does NOT rollback status

### 6. Register Services in Program.cs

- Add `builder.Services.AddResend(...)` with API key from config
- Add `builder.Services.AddScoped<IEmailService, EmailService>()`
- Add email config section to `appsettings.json`

### 7. Build & Verify

- `dotnet build` passes
- Manual test via Swagger: create order → check console for email send log
