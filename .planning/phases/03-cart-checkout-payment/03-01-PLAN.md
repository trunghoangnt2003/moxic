<name>Create OrdersController with POST + GET endpoints</name>

  - API/Moxic.Api/Controllers/OrdersController.cs

<action>
Create OrdersController.cs with two endpoints:

**POST /api/orders** — Create order from checkout submission.
- Accept JSON: { items: [{ gameId: guid, price: decimal }], customerPhone: string, customerXboxEmail: string, customerXboxPassword: string, customerZalo?: string, paymentMethod: string }
- Validate: items not empty, phone not empty, Xbox email + password not empty
- Generate order code: MOXIC-{yyyyMMdd}-{5 random alphanumeric uppercase}
- Encrypt Xbox password using IDataProtectionProvider — create a protector with purpose "XboxPassword". Store encrypted as Base64 in CustomerXboxPasswordEncrypted.
- Calculate TotalAmount from items sum
- Create Order record with Status = Pending, PaymentMethod parsed from string (Bank/Crypto)
- Create OrderDetail records for each item (snapshot GameName by querying Game table)
- Return 201 with { id, orderCode, totalAmount, createdAt }

**GET /api/orders/{orderCode}** — Get order by order code (for confirmation page).
- Query Order by OrderCode (unique index exists)
- Include OrderDetails
- Also fetch active PaymentConfig (first from PaymentConfigs table)
- For PaymentConfig, generate presigned URLs: call _minio.GetPresignedUrlAsync(bucket, objectKey, expiry) for bank QR and crypto QR.
- Return: { orderCode, items: [{ gameName, price }], totalAmount, status, createdAt, paymentConfig: { transferSyntaxTemplate, bankQrUrl, cryptoQrUrl } }
- Return 404 if not found

Add DTOs for both request/response to Dtos.cs (or inline in controller file — your choice). Follow same DTO patterns as existing GameListItemDto.

Follow existing controller patterns: [Route("api/[controller]")], [ApiController], constructor injection of MoxicDbContext, IMinioService, IDataProtectionProvider, IConfiguration.
</action>
