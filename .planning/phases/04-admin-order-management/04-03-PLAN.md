<name>Create OrderList page component</name>
<files>
  - Moxic.Admin/src/pages/OrderList.tsx
</files>
<action>
Create OrderList.tsx following GameList.tsx pattern:

**Interface:**
- AdminOrderListItem: id, orderCode, customerPhone, totalAmount, status, paymentMethod, itemCount, isPreorder, releaseDate?, createdAt

**State:**
- orders: AdminOrderListItem[], search: string, statusFilter: string ("All" by default), fromDate: string, toDate: string, page: number, totalCount: number, loading: boolean
- selectedOrder: AdminOrderDetailResponse | null (for modal)

**Data fetching:**
- useEffect fetches from /api/admin/orders with query params: search, status, fromDate, toDate, page, pageSize
- Parse response as { items, totalCount, page, pageSize }

**Header:**
- "Orders" title with count
- "Total revenue" stat card (sum of all orders' totalAmount -- could compute from list)

**Filter toolbar:**
- Search input (steam-input class, Search icon from lucide)
- Status dropdown: All, Pending, Verifying, Installing, Completed, Cancelled
- From date input, To date input (type="date" with steam-input class)
- Clear filters button

**Table (steam-table class):**
- Columns: Order Code, Customer, Items, Total, Status, Payment, Date
- Status column uses same badge pattern as GameList:
  - Pending: yellow/warning
  - Verifying: blue
  - Installing: orange
  - Completed: green
  - Cancelled: red
- Preorder: show Clock icon + "Preorder" badge, ReleaseDate column
- Click row -> open modal with selectedOrder detail
- Click outside row area doesn't trigger (use onClick on tr)

**Pagination:**
- Simple prev/next buttons at bottom
- Show "Page X of Y" text

**Loading state:** Skeleton rows or loading text
**Empty state:** "No orders found" with icon
**Error state:** Alert with retry button

**Stats cards** (matching GameList pattern):
- Total Orders
- Pending (count)
- Verifying (count)
- Completed (count)
</action>
</task>

<task type="auto">
<name>Create OrderDetailModal component</name>
<files>
  - Moxic.Admin/src/pages/OrderDetailModal.tsx
</files>
<action>
Create modal overlay component:

**Props:** orderId: Guid, onClose: () => void, onStatusChange: () => void (refresh list)

**Data fetching:**
- Fetch GET /api/admin/orders/{orderId} on mount
- Response includes decrypted password

**Modal layout (steam-card styling):**
- Dark overlay background (bg-black/60)
- Modal panel centered, max-w-2xl, bg-steam-surface, border border-steam-border, rounded

**Sections:**

1. **Header:** OrderCode, date, status badge (same colors as table), close X button

2. **Items list:** Simple table/list showing game name + price per item

3. **Total:** TotalAmount formatted as currency

4. **Customer info:**
   - Phone number
   - Xbox Email
   - Xbox Password: initially masked as "•••••••••"
   - Eye icon (Eye/EyeOff from lucide-react) to toggle visibility
   - On toggle: show plaintext password or mask
   - Zalo/FB (if present)

5. **Notes:** Show Notes field if present, otherwise hide

6. **Action buttons** (bottom of modal, right-aligned):
   - Show buttons based on current status:
     - Pending: "Received Payment" (Verifying), "Cancel" (danger)
     - Verifying: "Installing" (Installing), "Cancel" (danger)
     - Installing: "Completed" (green)
     - Completed: no action buttons (show "Completed" badge only)
     - Cancelled: no action buttons, show "Cancelled" badge
   - Each button calls PUT /api/admin/orders/{id}/status with { status: "NextStatus" }
   - On success: call onStatusChange to refresh parent list, close modal
   - Show loading spinner on button during API call
   - Confirm dialog for Cancel action

**Loading state:** Show spinner or skeleton while fetching detail
**Error state:** Show "Failed to load order detail" with retry button
</action>
