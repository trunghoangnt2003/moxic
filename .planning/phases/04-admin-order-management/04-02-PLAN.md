Create AdminOrdersController.cs following AdminGamesController pattern:

**Constructor:** Inject MoxicDbContext, IDataProtectionProvider, IMinioService, IConfiguration.

**GET /api/admin/orders** -- Paginated list, newest first.
- Query params: status (string optional), fromDate (DateTime?), toDate (DateTime?), search (string optional -- matches OrderCode or CustomerPhone), page (int, default 1), pageSize (int, default 20)
- Build query: start with _db.Orders.Include(o => o.Details).AsQueryable()
- Filter by status if provided (parse string to OrderStatus enum)
- Filter by date range if provided
- Filter by search (orderCode.Contains or customerPhone.Contains)
- Order by CreatedAt descending
- Get total count before pagination
- Apply Skip/Take for pagination
- Map to AdminOrderListItem: check if any item's GameId is a Preorder game with future release date -> set IsPreorder/ReleaseDate
- Return AdminOrderListResponse with Items, TotalCount, Page, PageSize

**GET /api/admin/orders/{id:guid}** -- Full detail.
- Load order with Details included
- Decrypt Xbox password: protector.Unprotect(Convert.FromBase64String(order.CustomerXboxPasswordEncrypted)) -> UTF8 string
- Map to AdminOrderDetailResponse with decrypted password
- Return 404 if not found

**PUT /api/admin/orders/{id:guid}/status** -- Status transition.
- Accept { status: "Verifying" | "Installing" | "Completed" | "Cancelled" }
- Load order (without details)
- Parse requested status from string
- Validate transition rules:
  - Pending -> Verifying (allowed)
  - Pending -> Cancelled (allowed)
  - Verifying -> Installing (allowed)
  - Verifying -> Cancelled (allowed)
  - Installing -> Completed (allowed)
  - Any other transition -> 400 Bad Request with error message
- Preorder check: if transitioning FROM Pending, check order details for preorder games. If any detail's Game has Status == Preorder && ReleaseDate > DateTime.UtcNow, block with 400: "Cannot process preorder before release date"
- Set order.Status, order.UpdatedAt = DateTime.UtcNow
- If Cancelled, update Notes if provided in body
- SaveChanges and return NoContent()
</action>
